# PlateWatch
Aplicacion Android nativa y offline para vigilancia de placas.

## Estado 0.1.1
Esta etapa incorpora enumeracion Camera2, seleccion de camara, preview CameraX, `ImageAnalysis` con `KEEP_ONLY_LATEST` y metricas reales. El ALPR aun no esta conectado y la interfaz lo informa expresamente; no hay reconocimiento simulado.

## Ejecucion
Abrir la raiz en Android Studio, usar JDK 17, sincronizar Gradle y ejecutar en un dispositivo API 24 o superior.
