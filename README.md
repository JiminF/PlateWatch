# PlateWatch

Aplicacion Android nativa para deteccion y reconocimiento offline de placas vehiculares.

## Estado

Etapa 1 en desarrollo. Esta entrega contiene la base Android, enumeracion real de camaras internas, contratos desacoplados de camara y ALPR, normalizacion y estabilizacion temporal. Todavia no incluye preview, UVC ni un modelo ALPR y no simula esas funciones.

## Abrir

1. Abrir la carpeta raiz en Android Studio.
2. Usar JDK 17.
3. Sincronizar Gradle.
4. Ejecutar en un dispositivo Android API 24 o posterior.

## Paquete

`co.intecdl.platewatch`
